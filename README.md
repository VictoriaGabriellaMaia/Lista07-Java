# Lista07-Java

## Array (Matriz) em Java

1) Leia os elementos de uma matriz 5 x 5 a partir do teclado. O algoritmo deve:  
a. Imprimir a matriz informada.  
b. Imprimir os elementos armazenados nas posições em que o índice da linha é par e o índice da coluna é ímpar.

2) Leia duas matrizes 2x2 a partir do teclado, some as duas matrizes e apresente a matriz resultante na tela.

3) Leia os elementos de uma matriz 6 x 6. O algoritmo deve:  
a. Apresentar a matriz informada.  
b. Somar os elementos das colunas pares.  
c. Somar os elementos das colunas ímpares.  
d. Calcular a diferença entre as duas somas.  
e. Apresentar os valores calculados na tela.
